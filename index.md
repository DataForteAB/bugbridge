# Bugbridge for Jira

BugSnag errors become tracked Jira work — created automatically, deduplicated when they recur, and
resolved in both directions.

An Atlassian Forge app by **DataForte AB**, available on the Atlassian Marketplace.

## What it does

- A BugSnag alert creates a Jira issue with level, environment, event count, culprit and a link back.
- The same error recurring comments on the existing issue with an updated count, instead of filling
  your backlog with duplicates.
- Moving the Jira issue to a done status resolves it in BugSnag; resolving in BugSnag leaves a note on
  the Jira issue.
- Rules per BugSnag project decide the target Jira project, issue type, minimum event count, levels
  and environments.
- An hourly reconciliation scan picks up anything a dropped webhook would have lost.
